# Project Statement

## Simple Bank Management System

The project is a menu-driven Python application designed to demonstrate basic banking operations. It allows users to create an account, log in using an account number and PIN, view account information, check balance, deposit money, withdraw money, transfer money to another account, and log out.

Account records are maintained in an in-memory Python dictionary. Each account contains the customer's name, mobile number, PIN, and balance. The project demonstrates fundamental Python programming concepts including dictionaries, loops, conditional statements, input/output, validation, and nested control flow.

The system is intended as an educational project and does not represent a production banking application.
